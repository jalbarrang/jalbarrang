# Hi, I'm Juan

I build tooling for AI coding agents, mostly for [pi](https://github.com/earendil-works/pi-mono).
What I care about is the part that decides whether you can trust one: sandboxes,
permissions, and what happens when a step fails instead of succeeding.

I also build pages and other web tools for fun.

I'm available for senior full-stack or agent-tooling work, remote, UTC-3.

## Libraries

- [**pi-command-sandbox**](https://github.com/jalbarrang/pi-command-sandbox) — Shell-command
  validation for "read-only" agent modes, shared by the other extensions, still wip.
- [**taskman**](https://github.com/jalbarrang/taskman) — My own task manager for coding agents.
- [**honse-sim**](https://github.com/jalbarrang/torena-sim) — Race-simulation for honse-game, as a Rust
  library.

## Pages
